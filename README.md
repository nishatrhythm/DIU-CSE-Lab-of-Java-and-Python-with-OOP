## How to Run the Programs

### Running Python
```bash
python path/to/file.py
```
*In Jupyter Notebook / Google Colab:*
Open any code snippet directly in a notebook cell and execute with `Shift + Enter`.

### Running Java
```bash
javac path/to/FileName.java
java path/to/FileName
```
*In IntelliJ IDEA / Eclipse:*
Open the project folder, configure JDK 8+, open any `.java` file, and click the green Run button.
